# Validation

Run the structural checks from the repository root:

```bash
python kinesis.py check-graph
python kinesis.py validate Engine/Templates/Project --template
python -m unittest discover -s tests -v
```

Project validation checks identity, known expertise/contracts, recipe relationships, positive rational timebases, half-open frame intervals and completion evidence states. Install `requirements.txt` to add JSON-schema validation. Without that dependency, only built-in semantic checks run.

## Production evidence

Configuration validity is separate from rendered appearance, actual playback, audible quality, mobile readability and placement review. Record observations against the actual output revision. A `pass` label is a record supplied by the production workflow, not independent proof that the toolkit watched a video.

Retain historical design and recipe sources, not only their version labels. The current toolkit does not archive versions automatically, align speech, calculate visual collisions or render videos. Shared contracts describe those responsibilities and their required handoffs. Select and verify actual tools for each production.
