# Production Workflow

## Establish the project

Define audience, message, media, output format and constraints. When references are supplied, assign their roles and distinguish observed cues from inferred or invented structure. Select a coherent visual direction and keep project-specific decisions in Project.json.

## Plan an episode

Create an episode through the toolkit. Map beats, source/output ranges, speech and visual cues. Select only the relevant editorial owners, technical expertise and production contracts. Give recipe instances explicit versions and parameters.

## Construct and render

Develop original key states from intent; match silhouette, composition, camera and value relationships only when comparison is requested. Evaluate motion from explicit time and parameters. Probe the intended rendering path with an expensive representative frame and short segment before full production. Keep assets and editable source in the project; write generated media to Outputs.

## Review and revise

Inspect stills, actual encoded playback, speech and phone-scale layout separately. Inspect intermediate states and frames around time-critical boundaries. Track each issue to its owner, source revision and affected interval. Recheck the failure and its adjacent transitions after a correction.

## Deliver and retain

Record final paths, exact dimensions/fps/duration, source/build lineage and gate results. Keep historical project and recipe sources available for pinned episode versions. The toolkit checks structure; production review still requires actual artifacts and observation.
