# Project Template

Use `python kinesis.py init <project-id> --name '<project name>'` from the repository root. Keep this template generic: no client palettes, proprietary assets, provider credentials or assumed platform UI percentages.

The eight recipe entries are parameter patterns. Implement and inspect a recipe before marking it approved. Each new episode inherits a project ID and design-version label; retain the corresponding historical source revisions when rebuilding an older episode.
