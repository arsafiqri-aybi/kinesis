# Creative Learning

Use continuing observation to expand creative choices. Activate this mechanism when a user supplies a lesson, a reference, feedback or an unexpected production result. A reference is optional learning material; original production can begin from an idea, a script, a sound, a constraint or an experiment. Match a reference only when the user requests that relationship.

## Interpret the learning request

Resolve whether the request asks for analysis, persistent improvement, a reconstruction or a new production. Analysis alone authorizes observation, not installation or production. A request to improve the engine authorizes scoped knowledge changes. Keep the study separate from any finished video.

## Observe before explaining

Inspect the supplied medium. Record its identity, duration/timebase, inspected intervals and method. Separate visible states, inferred construction, proposed perceptual effects and untested implementation choices. Sample more densely where an action changes rapidly. Contact sheets support state/order comparisons; actual playback is needed to judge smoothness, pacing and audiovisual timing. Record unreviewed audio and missing playback explicitly. A moving panel does not prove a 3D camera; a luminous edge does not prove a particular plugin or shader.

## Extract a transferable mechanism

For each useful discovery, identify:

- **Intent:** what the construction may help the audience understand or feel.
- **Relationship:** which properties, objects or events depend on each other.
- **Controls:** timing, scale, trajectory, contrast, density or other editable parameters; use measured values only when actually measured.
- **Conditions:** situations in which the relationship is useful.
- **Failure:** how it can distract, confuse, obscure content or become repetitive.
- **Alternative:** a different realization that preserves the intended relationship.
- **Evidence:** observation scope, uncertainty and what would test the explanation.

Extract relationships independently from the source's brand, palette, fonts and shot sequence. For example, an object and a later label may share color to preserve identity across a cut. The transferable choice is correspondence; another project may use shape, rhythm or position instead. Keep exact colors and actual media in the study/project.

## Expand the creative space

When useful, vary medium, scale, timing character, spatial arrangement or visual density while preserving the relationship under study. Explore alternatives only where they resolve a creative question; impose no quota, fixed look or mandatory effect. Contrast an energetic realization with a quiet one when this tests whether a lesson is independent of style. A scene may deliberately hold still. Do not turn the latest attractive reference into a universal production formula.

## Integrate at the correct owner

Search the existing expertise before adding an owner. Deepen an existing decision when it already owns the mechanism. Add a specialization only for a distinct decision responsibility and output. Keep shared algorithms with their current owner and connect conditional handoffs through the integrated graph. Kinesis routes learning and revisions; Motion owns craft knowledge; the study owns source-specific observations; the project owns identity, components and creative choices.

Preserve source studies under an independent learning project, outside the main-engine package. The main engine retains concise, source-independent procedures and explicit knowledge status. Keep a study-to-owner change record outside the package so later lessons can corroborate, qualify or contradict it.

## Revisit rather than accumulate blindly

On a new lesson, compare its mechanism with existing knowledge. Merge equivalent explanations, preserve meaningful alternatives and narrow claims when observations conflict. Record proposed, applied, rendered and reviewed states separately. A structural graph pass certifies connectivity and consistency; it does not certify visual quality or generalization. Promote a broadly reusable candidate with an explicit hypothesis label when testing is absent; call it validated only within the contexts actually examined.

## Operational handoff

Send attention hypotheses to Attention Direction, action dependencies to Motion Choreography, UI state logic to UI Choreography and product claims to Product Film Direction. Use reference-curation for source handling and reference-matching only when comparison against selected targets is relevant. Return creative hypotheses to visual-direction; return discrepancies to the responsible craft owner.

## Learning across different editing styles

Use contrasting examples to separate function from appearance. Compare the text role, semantic grouping, attention relationship, source/insert role, treatment and continuity choice. A minimal caption and an elaborate text scene may solve different tasks. Integrate the useful conditional relationship with Editorial-Reasoning.md and Expressive-Text.md and the existing craft owners; preserve meaningful alternatives rather than average all examples into one aesthetic. Do not assume a filmed screen reveals the renderer used or that a visible subtitle establishes speech alignment.
