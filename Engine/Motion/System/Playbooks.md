# Integration Playbooks

Activate only the responsibilities required by the brief. A handoff is complete when its payload, precision, revision and evidence status are explicit. Use a shared rational timebase and immutable asset IDs throughout.

## Talking-head explanation with animated captions

Ingest and inspect footage → map semantic beats → align actual speech → caption readable phrases → choose card or cutaway for concepts that benefit from explanation → solve layout over time → mix voice first → render placement variants → inspect playback. Reject decorative emphasis that changes meaning. A transcript correction changes caption layout; replacing audio also invalidates alignment. Inspect early, middle, late cues and speaker switches.

## Reference-led coded explainer

Assign reference roles → resolve styleframes → decompose shapes and camera → choose procedural representation → reconstruct major appearance → design explicit time evaluation → insert the shot into the editorial time map → inspect identity and reading holds → render. A reference change first invalidates the properties it governs. Do not replace editable geometry with an embedded reference raster under a full-code brief.

## Narrated character insert

Reuse character master → interpret the approved acting beat → select body/face controls → generate narration only with actual authorized provider access → measure audio → obtain supported alignment or author reviewed cues → drive visemes and acting separately → check contact/gaze/identity → mix and review the combined clip. A plausible mouth movement is not verified phoneme alignment. Preserve OpenAI narration preferences and existing character ownership.

## Tracked callout or freeze-frame effect

Choose source subject and editorial purpose → normalize media with a coordinate map → estimate track/mask and valid ranges → attach an element through source-to-output transforms → resolve foreground occlusion → inspect loss/re-entry → composite → review. Confidence loss triggers manual anchors, a planned gap or a simpler cut; it never licenses an unreviewed identity switch.

## Placement or language change

Keep semantic edit and asset lineage shared; fork only changed copy, layout and relevant output settings. New copy/font invalidates measured text bounds. New placement invalidates platform/UI checks. New spoken language invalidates audio duration and dialogue alignment. Recompute the required time mapping, variant layouts, render signatures and completion gates.

## Evidence ladder

Distinguish structurally valid knowledge, runnable tools, successful render, visually reviewed stills, actual playback review and real placement review. Mark each pass/fail/unverified independently. A graph test does not establish a good edit, and successful encoding does not prove smooth motion or natural narration.
