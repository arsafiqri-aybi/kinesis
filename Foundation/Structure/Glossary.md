# Glossary

## Terms

These definitions follow this library's usage. Theory-dependent meanings are qualified explicitly.

| Term | Meaning and limit |
| --- | --- |
| Motion | Change of position, orientation, or spatial arrangement under specified comparison rules; broader uses are stated separately |
| Change | Nonconstancy of a history under selected equality criteria |
| State | An alternative description of a system in a given context |
| Configuration | A system's arrangement; not always a sufficient complete dynamical state |
| Identity | Criteria for the referent remaining the same system or part |
| Distinction | Meaningful inequality within a stated framework |
| Representational equivalence | Descriptions expressing the same physical state under theoretical rules |
| Equivalence relation | A reflexive, symmetric, transitive relation |
| Quotient space | Equivalence classes with additional structure when specified |
| Coarse-graining | A map retaining partial information and potentially merging distinct states |
| Observable | A theory-defined quantity or measurement structure; not always a pre-existing definite value |
| History | States or configurations related to temporal contexts |
| Geometric path | A traversed trace or curve, distinguished from traversal timing |
| Event | In relativity, a spacetime element, not an entire extended process |
| Partial order | An order not requiring every pair to be comparable |
| Total order | An order requiring pairwise comparability |
| Duration | A temporal interval quantity under a specified structure or procedure |
| Parameter | A history-domain label; not necessarily physical clock time |
| Reparametrization | A change of traversal parameter under specified transformation conditions |
| Coordinate time | The temporal coordinate of a description |
| Proper time | Geometric duration along a timelike curve in relativity |
| Simultaneity | Events having the same time under a selected structure |
| Causality | Possible influence according to a theory; not merely list order |
| Position | A place in a space or relative to spatial relations |
| Coordinates | Labels representing points or configurations |
| Physical space | Spatial structure modelled as physical locations or relations |
| Configuration space | The set of configurations considered |
| Phase space | Position–momentum state space in suitable classical formulations |
| Topology | An open-set structure determining, among other things, continuity |
| Distance metric | A positive distance function with identity, symmetry, and the triangle inequality |
| Lorentzian metric | A spacetime bilinear structure with a specified signature; not a positive distance metric |
| Affine structure | Structure permitting point differences without a privileged origin |
| Smooth manifold | A space with compatible local coordinates for differential calculus |
| Reference | A comparison rule or system for relations and changes |
| Inertial frame | A frame with theory-defined free-motion structure |
| Symmetry | A transformation preserving specified structure |
| Invariant | A property or quantity preserved by a stated transformation class |
| Gauge | Theory-defined representational redundancy, not every symmetry |
| Continuity | Preservation of topological proximity through open-set preimages |
| Differentiability | Existence of an appropriate derivative structure |
| Velocity | A position-change vector per time parameter when structure and limits permit |
| Speed | Rate magnitude under a metric or norm, without vector direction |
| Rest | Constant configuration on a stated domain under a specified reference and equality |
| Kinematics | The structure of motion descriptions |
| Dynamics | Laws restricting histories in a theory |
| Stationary | Unchanging in a specified sense: state, distribution, statistics, or quantity |
| Probability current | A quantum-theoretical structure associated with probability conservation, not an individual-trajectory definition |
| Measurand | The quantity intended to be measured |
| Identifiability | Uniqueness of the queried property among data-compatible models or histories |
| Uncertainty | Limits on value determination given information and a measurement model |
| Motion perception | Experience or judgement of motion, distinguished from stimuli and physical inference |

## Notation

| Symbol | Usage |
| --- | --- |
| \(S\) | State space |
| \(Q\) | Configuration space |
| \(T\) | Temporal domain |
| \(s(t),q(t)\) | State or configuration along a history |
| \(x,\mathbf r\) | Spatial location or coordinates, context-dependent |
| \(\sim,[s]\) | Equivalence and equivalence classes |
| \(d\) | Positive distance metric |
| \(g_{\mu\nu}\) | Lorentzian metric components with \((-+++)\) convention |
| \(\lambda\) | General parameter |
| \(\tau\) | Proper time on a timelike curve |
| \(R\) | Rotation matrix or reference name, specified locally |
| \(H,\mathcal O\) | Observation maps; not a Hamiltonian unless stated |
| \(\psi,\rho,j\) | Wavefunction, probability density, probability current |
| \(c,\hbar\) | Vacuum speed of light and reduced Planck constant |

Repeated tensor indices are summed. Examples such as \(q=t^3\) use dimensionless mathematical variables or normalized coordinates; physical quantities require appropriate dimensional factors.
