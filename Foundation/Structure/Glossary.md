# Glossary

## Istilah

Definisi berikut mengikuti penggunaan dalam perpustakaan ini. Jika suatu istilah berubah makna menurut teori, batas tersebut disebutkan.

| Istilah | Makna dan batas |
| --- | --- |
| Motion / gerakan | Perubahan posisi, orientasi, atau susunan spasial terhadap aturan perbandingan tertentu; penggunaan lebih luas dinyatakan tersendiri |
| Perubahan | Ketidakkonstanan riwayat menurut kriteria kesetaraan yang dipilih |
| Keadaan | Alternatif deskripsi sistem pada konteks tertentu |
| Konfigurasi | Susunan sistem; tidak selalu cukup sebagai keadaan dinamis lengkap |
| Identitas | Kriteria bahwa referen yang dibicarakan masih sistem atau bagian yang sama |
| Perbedaan | Ketidaksetaraan yang bermakna dalam kerangka yang disebutkan |
| Kesetaraan representasi | Dua deskripsi menyatakan keadaan fisik sama menurut aturan teori |
| Relasi ekuivalensi | Relasi refleksif, simetris, transitif |
| Ruang hasil bagi | Himpunan kelas ekuivalensi beserta struktur tambahan bila ditentukan |
| Coarse-graining | Pemetaan yang mempertahankan sebagian informasi dan dapat menggabungkan keadaan berbeda |
| Observabel | Besaran atau struktur pengukuran yang pengertiannya ditentukan teori; bukan selalu nilai pasti yang telah ada |
| Riwayat | Pengaitan keadaan atau konfigurasi dengan konteks temporal |
| Lintasan geometris | Jejak atau kurva yang ditelusuri, dibedakan dari informasi waktu penelusurannya |
| Peristiwa / kejadian | Dalam relativitas, elemen ruang-waktu; tidak sama dengan keseluruhan proses berdurasi |
| Orde parsial | Relasi urutan yang tidak mengharuskan semua pasangan dapat dibandingkan |
| Orde total | Orde yang menambahkan keterbandingan setiap pasangan |
| Durasi | Besaran selang temporal menurut struktur atau prosedur yang ditentukan |
| Parameter | Label domain riwayat; belum tentu waktu yang diukur jam fisik |
| Reparameterisasi | Perubahan parameter penelusuran, dengan syarat transformasi yang disebutkan |
| Waktu koordinat | Koordinat temporal suatu deskripsi |
| Waktu proper | Durasi geometris sepanjang kurva timelike dalam relativitas |
| Keserentakan | Hubungan bahwa kejadian dianggap memiliki waktu sama menurut struktur yang dipilih |
| Kausalitas | Hubungan kemungkinan pengaruh sesuai teori; tidak disamakan dengan urutan daftar |
| Posisi | Kedudukan dalam ruang atau terhadap hubungan spasial tertentu |
| Koordinat | Label untuk merepresentasikan titik atau konfigurasi |
| Ruang fisik | Struktur spasial yang dimodelkan sebagai lokasi atau hubungan fisik |
| Ruang konfigurasi | Himpunan seluruh konfigurasi yang dipertimbangkan |
| Ruang fase | Ruang keadaan posisi–momentum dalam formulasi klasik yang sesuai |
| Topologi | Struktur himpunan terbuka yang antara lain menentukan arti kontinuitas |
| Metrik jarak | Fungsi jarak positif dengan identitas, simetri, dan ketaksamaan segitiga |
| Metrik Lorentzian | Struktur bilinear ruang-waktu dengan signature tertentu; bukan metrik jarak positif |
| Struktur afin | Struktur yang memungkinkan perbedaan titik tanpa asal istimewa |
| Manifold mulus | Ruang dengan koordinat lokal yang kompatibel untuk kalkulus diferensial |
| Acuan | Aturan atau sistem pembanding untuk menyatakan hubungan dan perubahan |
| Kerangka inersial | Kerangka dengan struktur gerak bebas yang ditentukan teori |
| Simetri | Transformasi yang mempertahankan struktur tertentu |
| Invarian | Sifat atau besaran yang dipertahankan oleh kelas transformasi yang disebutkan |
| Gauge | Redundansi representasi yang ditentukan teori; tidak identik dengan semua simetri |
| Kontinuitas | Pelestarian kedekatan topologis dalam arti prabayang himpunan terbuka |
| Diferensiabilitas | Keberadaan struktur turunan yang sesuai |
| Kecepatan | Vektor perubahan posisi per parameter waktu jika struktur dan limitnya tersedia |
| Kelajuan | Besar laju menurut metrik atau norma tertentu; tidak memuat arah vektor |
| Diam | Konfigurasi tetap pada domain yang disebutkan terhadap acuan dan kesetaraan yang ditentukan |
| Kinematika | Struktur deskripsi gerakan |
| Dinamika | Hukum yang membatasi riwayat dalam teori tertentu |
| Stasioner | Tidak berubah dalam pengertian yang harus disebutkan: keadaan, distribusi, statistik, atau besaran tertentu |
| Arus probabilitas | Struktur dalam teori kuantum yang terkait konservasi probabilitas; bukan definisi lintasan individual |
| Measurand | Besaran yang dimaksudkan untuk diukur |
| Keteridentifikasian | Ketunggalan sifat yang ditanyakan di antara model atau riwayat yang kompatibel dengan data |
| Ketidakpastian | Keterbatasan penentuan nilai berdasarkan informasi dan model pengukuran |
| Persepsi gerakan | Pengalaman atau penilaian gerak; dibedakan dari stimulus dan inferensi fisik |

## Notasi

| Simbol | Penggunaan |
| --- | --- |
| \(S\) | Ruang keadaan |
| \(Q\) | Ruang konfigurasi |
| \(T\) | Domain temporal |
| \(s(t),q(t)\) | Keadaan atau konfigurasi sepanjang riwayat |
| \(x,\mathbf r\) | Lokasi atau koordinat spasial menurut konteks |
| \(\sim,[s]\) | Kesetaraan dan kelas ekuivalensi |
| \(d\) | Metrik jarak positif |
| \(g_{\mu\nu}\) | Komponen metrik Lorentzian dengan konvensi \((-+++)\) |
| \(\lambda\) | Parameter umum |
| \(\tau\) | Waktu proper pada kurva timelike |
| \(R\) | Matriks rotasi atau nama acuan; arti dinyatakan setempat |
| \(H,\mathcal O\) | Pemetaan observasi; bukan Hamiltonian kecuali disebutkan |
| \(\psi,\rho,j\) | Fungsi gelombang, densitas probabilitas, arus probabilitas |
| \(c,\hbar\) | Kecepatan cahaya dalam vakum dan konstanta Planck tereduksi |

Indeks berulang pada rumus tensor dijumlahkan. Contoh seperti \(q=t^3\) menggunakan variabel matematis tanpa satuan atau koordinat yang telah dinormalisasi; untuk besaran fisik, faktor bersatuan yang sesuai harus disertakan.
